### Core Architecture & Technical Thesis

I engineer high-performance systems software, low-latency Windows utilities, and protocol-level orchestration layers for autonomous AI agent swarms. My work focuses on deterministic execution stacks, memory-safe infrastructure, and optimizing developer wetware through bimodal input pipelines and spatial memory architectures.

* **Systems Programming:** Native Win32 event loops, immediate-mode GUIs (`egui`), zero-allocation data structures, and asynchronous networking (`tokio`).
* **AI Agent Topologies:** Model Context Protocol (MCP) servers, multi-agent transactional blackboard routers, and semantic ingestion pipelines.
* **Developer Ergonomics:** Custom Nushell environments, terminal-first IPC automation, and local-first knowledge graphs.
